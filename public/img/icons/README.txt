Drop the real in-game icons here (white or coloured shape on transparent, svg or png, lowercase file names):
  element/heat.svg  cryo.svg  nature.svg  electric.svg  physical.svg
  class/guard.svg  caster.svg  striker.svg  supporter.svg  vanguard.svg  defender.svg
  rarity/star.svg
They are picked up automatically (tinted with the box colour) and replace the wiki icons.
Without these files the site uses the official icons from endfield.wiki.gg (Guard.png, Support.png, Heat.png, Star.svg ...),
and the stand-in glyphs if those cannot be loaded.
The site checks once a day per browser; clear localStorage key "et.icoMap.v3" to re-check immediately.
